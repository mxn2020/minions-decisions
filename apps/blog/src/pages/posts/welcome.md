# Welcome to Minions Decisions

We're excited to introduce **Minions Decisions** — Logged decisions with rationale, alternatives, and outcome.

## What's Included

- **TypeScript SDK**: `npm install @minions-decisions/sdk`
- **Python SDK**: `pip install minions-decisions`
- **CLI**: `npm install -g @minions-decisions/cli`

## Getting Started

Check out the [documentation](https://decisions.minions.help) for a full guide.
