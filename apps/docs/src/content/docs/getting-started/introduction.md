# Minions Decisions

Logged decisions with rationale, alternatives, and outcome

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-decisions/sdk`) — Core library for Node.js
- **Python SDK** (`minions-decisions`) — Python bindings
- **CLI Tool** (`@minions-decisions/cli`) — Command-line interface
- **Web App** — Interactive playground at [decisions.minions.wtf](https://decisions.minions.wtf)
