---
title: Installation
description: Install Minions Decisions packages
---

## TypeScript / Node.js

```bash
npm install @minions-decisions/sdk minions-sdk
```

## Python

```bash
pip install minions-decisions
```

## CLI

```bash
npm install -g @minions-decisions/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
